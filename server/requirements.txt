# The single dependency set for the server: this file installs the venv
# (scripts/dev-setup.sh), the CI job (.github/workflows/ci.yml) and the
# production image (Dockerfile). There used to be a second, loosely-pinned
# list at moana/requirements.txt that only the image read, which meant the
# thing deployed and the thing tested were never provably the same (#156).
#
# Fully pinned, transitive deps included — a freeze, so regenerate rather than
# hand-edit:
#   .venv/bin/pip install <pkg> && .venv/bin/pip freeze > requirements.txt
#
# It carries the test and typing packages (pytest, syrupy, *-stubs) into the
# image too. Harmless, and the file it replaced did the same; splitting dev
# from runtime is a separate job.
#
# gunicorn and whitenoise are here because settings_prod and entrypoint.sh
# need them, not because dev does. They were in the image's list only, which
# is why nothing outside a docker build could so much as import
# moana.settings_prod.
